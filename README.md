# React Step Navigation

A simple React UI project built to practice React state management with `useState`.

## Features

- Next and Previous navigation
- Three simple steps
- Circular step navigation
- Show / Hide content
- Active step styling
- Simple and clean UI

## Technologies

- React
- Vite
- JavaScript
- Tailwind CSS

## How It Works

The project uses React's `useState` hook to control the current step.

The steps work like this:

0 → 1 → 2 → 0

And Previous works in reverse:

2 → 1 → 0 → 2

The project also includes a simple Show / Hide functionality.
